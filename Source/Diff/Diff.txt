GameBase Diff Utility (.NET)
=============================

This tool compares two GameBase SQLite databases and writes an update database containing
only the changed or newly added games. The update database can be shared with the
database maintainer to merge your updates.

The .NET diff utility is implemented as a subcommand of GBMigrator.

USAGE
-----

GBMigrator diff <current-db> <backup-db> [output-db] [--letters <letters>]

Examples:
  GBMigrator diff C:\GameBase\Current.db C:\GameBase\Backup.db
  GBMigrator diff Current.db Backup.db update.db --letters A,B,C,0-9

Letters:
- Use A-Z to restrict by starting letter.
- Use 0-9 to include non-letter names.
- If omitted, all letters and 0-9 are included.

INSTRUCTIONS
------------

1) Get an up-to-date database from the database maintainer.

2) Make a backup of it (use a name like Backup.db).

3) Use the up-to-date database (not the backup) to collect the game info.

4) When you wish to submit your database changes, run the diff tool:

   - First select your current changed database
   - Then select the original backed up database
   - Pick the letters that you have changed (if you are not sure, select all)
   - Run the command and follow the prompts to enter your name, email, database name, and notes
   - Send the generated update.db to the database maintainer

5) Replace your backup database with the current database after submitting
   (the tool can do this for you when it finishes).

If you need the legacy VB6 Diff utility, see the Source/Diff folder history.
